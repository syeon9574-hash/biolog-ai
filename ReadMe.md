# 📌 Project Overview

## 🌱 Biolog AI

Biolog AI는 초등학생을 위한  
**AI 기반 생물 관찰일지 플랫폼**입니다.

학생들은 생물 사진과 관찰 내용을 기록하고,  
AI는 사진 분석을 통해 생물의 특징과 관찰 포인트를 제공합니다.

교사는 학생들의 활동 데이터를 관리하며  
학습 과정을 효율적으로 확인할 수 있습니다.

<br>

### 🎯 목표

- 생물 관찰 활동의 흥미 향상
- AI 기반 학습 경험 제공
- 학생 중심 자기주도 학습 지원
- 교사의 관리 효율 개선
- 디지털 교육 데이터 구축

<br>

# 📈 What I Focused On

## 💡 프로젝트에서 중요하게 고민한 부분

### 1. 교육 서비스에 적합한 UX 설계

초등학생도 쉽게 사용할 수 있도록  
복잡한 기능을 단순한 흐름으로 재구성했습니다.

<br>

### 2. AI 기능의 자연스러운 연결

AI 기능이 단순 부가기능이 아닌  
학습 흐름 속에 자연스럽게 녹아들도록 설계했습니다.

<br>

### 3. 감성적인 UI 디자인

아이들이 거부감 없이 사용할 수 있도록  
부드러운 컬러와 카드형 인터페이스를 적용했습니다.

<br>

### 4. 역할 기반 구조 설계

학생과 교사의 사용 목적이 다르기 때문에  
권한과 UX 흐름을 분리하여 설계했습니다.
